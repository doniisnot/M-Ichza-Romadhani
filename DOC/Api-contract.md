# API Design Contract & Decision Documentation## Sistem Informasi Koperasi Simpan Pinjam Berbasis AI---### 1. Prinsip Desain & Integrasi- **Gaya Arsitektur**: RESTful API berbasis JSON.- **Komunikasi Service**: Synchronous HTTP POST antara Backend Laravel dan Dedicated Python ML Engine (FastAPI).- **Prinsip Human-in-the-Loop**: AI hanya memproduksi rekomendasi (`Yes/Diterima` atau `No/Ditolak`). AI **TIDAK BOLEH** merubah `status` pada `loan_applications` secara otomatis.---### 2. Penanganan SLA & Reliability- **SLA Latensi Scoring (NFR-05)**: Waktu pemrosesan ML Engine dibatasi maksimal **≤ 5 detik**.- **Timeout Configuration**: HTTP Client Backend Laravel dikonfigurasi dengan Read Timeout **4.5 detik**.- **Fallback Mechanism**:  - Jika ML Engine mengalami *Timeout* (> 5 detik) atau HTTP 500, sistem menangkap exception tersebut.  - Status pengajuan **TETAP pada `pending_review`**.  - Sistem menampilkan pesan terstruktur: *"Proses scoring AI mengalami batas waktu/gagal"*.  - Tidak ada perubahan otomatis ke status `approved` atau `rejected`.---### 3. Autentikasi & Keamanan Data- **Public/Client API**: Menggunakan JWT / Bearer Token berbasis Role-Based Access Control (RBAC).- **Inter-Service API** (Laravel ↔ FastAPI): Dilindungi menggunakan `X-API-Key` header khusus server-to-server.- **Isolasi Data Anggota**: Anggota hanya diizinkan mengakses pengajuan yang memiliki `member_id` milik akun yang bersangkutan.---### 4. Kode Error Standar| HTTP Status | Error Code | Keterangan || :--- | :--- | :--- || **400 Bad Request** | `ERR_INVALID_PAYLOAD` | Format JSON tidak valid / terdistorsi. || **422 Unprocessable**| `ERR_AI_INCOMPLETE_INPUT` | Salah satu dari 4 atribut wajib (`job`, `education`, `housing`, `loan`) kosong/invalid. || **500 Internal Error**| `ERR_AI_MODEL_FAILURE` | Kegagalan internal pada eksekusi model ID3 Python. || **504 Gateway Timeout**| `ERR_AI_SERVICE_TIMEOUT` | Eksekusi model melebihi batas waktu SLA 5 detik. |
